# QMS User Guide

Prepared for: Yahya Al Naaimi

## Daily Start

Open QMS at:

```text
https://qms.ysaidea.com
```

Start from My Work. It shows assigned reviews, actions, overdue items and notifications.

## Main Menu

- Home: main dashboard
- My Work: assigned work
- Reports: submitted reports and screening
- Safety: observations, incidents, investigations, risks and lessons learned
- Quality: NCR, CAPA, objectives, suppliers and actions
- Assurance: audits, inspections and compliance
- Analytics: trends and operational dashboards
- Administration: configuration for authorized users

## Create an Observation

Use Observation for unsafe acts and unsafe conditions.

1. Select Create.
2. Select Observation.
3. Choose Unsafe Act or Unsafe Condition.
4. Complete the pages:
   - Information
   - Description
   - Action Taken
   - Attachments
   - Review and Submit
5. Submit the Observation.

## Observation Information

Complete:

- Area
- Unit
- Date
- Time
- Observer
- Location
- Department
- Observation Type

## HSE Review

HSE reviewers open the Observation record and use the Review tab.

The reviewer decides:

- Valid
- Not Valid
- Needs More Information

The reviewer adds comments, risk level and a reporter-visible message only when needed.

## Action Tracker

Actions are optional. Use Action Tracker only when follow-up is required.

Each action should include:

- Action type
- Description
- Owner
- Department
- Due date
- Priority
- Evidence requirement
- Verification requirement

## Reporter Visibility

Reporters see only simple updates.

Reporters do not see:

- Internal HSE comments
- Internal review notes
- Investigation details
- CAPA details
- Action Tracker details
- Administration

## Good Reporting Practice

Write facts clearly.

Good example:

```text
At 09:20, the temporary barricade was missing from the maintenance work area near Gate 4. People could enter the area without warning.
```

Avoid short unclear notes such as:

```text
Bad setup. Needs fixing.
```

## Support

Use Help for system feedback.

Do not use Help to report unsafe acts, unsafe conditions or incidents. Use Observation or the correct reporting form.
